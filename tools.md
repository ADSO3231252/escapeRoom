# 🛠️ Herramientas del Proyecto — Escape Byte

## 🎮 Desarrollo del videojuego

| Herramienta | Uso |
|---|---|
| **Unity 6** | Motor principal del videojuego |
| **C#** | Lenguaje de programación del juego |
| **Universal Render Pipeline (URP)** | Renderizado 3D multiplataforma |
| **Unity Input System** | Controles para teclado, mouse y pantalla táctil |
| **Cinemachine** | Sistema de cámaras |
| **TextMeshPro** | Textos e interfaz del juego |
| **Unity UI (UGUI)** | Interfaces, menús y HUD |
| **Netcode for GameObjects** | Multiplayer de 1 a 4 jugadores |
| **Unity Transport** | Comunicación de red |
| **Multiplayer Services** | Gestión de sesiones multiplayer |
| **Relay** | Conexión entre jugadores |
| **Multiplayer Tools** | Herramientas de diagnóstico y desarrollo multiplayer |
| **Multiplayer Play Mode** | Pruebas de múltiples jugadores |
