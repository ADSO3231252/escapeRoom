# 📖 About the Project

PROJECT_NAME is an academic software engineering project developed by students of the **Analysis and Software Development (ADSO)** program at **SENA – Centro de Diseño e Innovación Tecnológica Industrial (CDTI)**.

The objective is to create an educational **first-person Escape Room** where players solve programming challenges while cooperating to escape before time runs out.

The project follows the **Scrum Framework**, uses **Jira Software** for project management, **GitHub** for version control, and **GitHub Wiki** as the official project documentation.

---

# 🎮 Game Overview

## Story

A brave female **Jack Russell Terrier** wakes up trapped inside a mysterious laboratory filled with programming puzzles, hidden rooms, encrypted terminals, and logical challenges.

Every solved puzzle unlocks a new area.

Every room teaches programming concepts.

Time is running out...

**Can you escape?**

---

# ✨ Main Features

- 🐶 Female Jack Russell main character
- 🎮 First-person gameplay
- 👥 Cooperative multiplayer (up to 4 players)
- 🧩 Programming-based puzzles
- 🌎 Cross-platform (Web, Android & iOS)
- ⏱ Countdown timer
- 🏆 Global leaderboard
- 💾 Smart autosave
- 📚 Interactive tutorial
- 🚀 Guided application tour
- 🎯 6 unique levels
- ⚡ 3 difficulty modes
- ♿ Accessibility support
- 🎨 Modern and clean user interface
- 💯 Free to play
