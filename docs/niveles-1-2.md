Level 1 and Level 2 Design

Level 1 — The Access Code

Name

The Access Code

Objective

Solve a basic programming puzzle to obtain the code that unlocks the door and allows the player to advance to Level 2.

Setting

The player is inside an abandoned programming laboratory. There is a computer, several screens, and a locked door.

Problem

The door is protected by a security system that requires a code. The computer contains a programming-related clue that the player must solve.

Puzzle

The computer displays the following code:

number = 5
result = number + 3
print(result)

The player must analyze the code and determine the number that will be displayed.

Core Mechanic

The player interprets simple programming code and uses the result to solve the challenge in the environment.

Solution

The result of "5 + 3" is 8.

The player enters 8 into the door's keypad to unlock it.

Time Limit

5 minutes.

Score

- 100 points: Solve without hints.
- 75 points: Use one hint.
- 50 points: Use two hints.

Victory Condition

The player correctly solves the puzzle and enters the code 8 into the door's keypad.

Defeat Condition

The timer reaches zero before the player solves the puzzle.

Difficulty

Easy.

---

Level 2 — The Locked System

Name

The Locked System

Objective

Solve a programming puzzle involving loops to activate the laboratory's main system.

Setting

After opening the door from Level 1, the player enters a server room. The main system is locked and displays a program that must be analyzed.

Problem

The security system cannot continue until the player correctly determines the result of a programming loop.

Puzzle

The computer displays the following code:

for i in range(1, 6):
    print(i)

The player must determine which numbers the program prints.

Core Mechanic

Understand how a "for" loop works and use the result to solve the challenge.

Solution

The loop prints:

1
2
3
4
5

Therefore, 5 numbers are displayed.

The player must enter 5 into the control panel to activate the system.

Time Limit

7 minutes.

Score

- 150 points: Solve without hints.
- 100 points: Use one hint.
- 75 points: Use two hints.

Victory Condition

The player correctly identifies the result of the loop and enters the number 5 to activate the system.

Defeat Condition

The timer reaches zero before the player completes the puzzle.

Difficulty

Medium.

---

Integration Between Level 1 and Level 2

The two levels are part of a linear story.

In Level 1, the player arrives at a programming laboratory and must solve a simple programming problem to obtain the access code. After entering the correct number, 8, the player unlocks the door.

After passing through the door, the player enters the server room, where Level 2 begins.

In Level 2, the player finds the main system locked. To continue, the player must solve a problem involving a "for" loop. After obtaining the correct result, the player activates the system.

The progression is:

Level 1 → Access Code → Door Unlocked → Server Room → Level 2 → System Activated

The difficulty increases progressively. Level 1 introduces variables and basic arithmetic, while Level 2 introduces programming loops.
